# 基于 arXiv 的论文补全

## 适用前提（先核对再动手）

- 论文主体（理论推导 + 数值分析）已完成，不需要修改推理过程与最终结论。
- 任务只是填充：摘要、引言、正文中可引用的支撑段落、结论、致谢、参考文献。
- 若用户实际要求修改推理/结论或从零写作，说明本 skill 不适用，并停止，不要强行执行。

## 工作流程

### 第 1 步：拆解初稿

通读全文，提取：

- 理论/方法关键词（如 Floquet 理论、紧束缚模型、密度泛函、蒙特卡洛等）
- 关键公式（记录公式符号与编号）
- 核心结论与数值结果

生成一份「理论 / 公式 / 结论」关键词清单，后续所有检索都基于它。

### 第 2 步：检索 arXiv（近一年，取前 40 篇）

用关键词清单运行 `scripts/search_arxiv.py`：

```bash
python scripts/search_arxiv.py "floquet theory" --limit 40 --years 1
```

脚本输出按相关度排序的列表（含 arXiv ID、标题、作者、发表日期、期刊信息 journal_ref 如有）。可加 `--json 文件名` 保存结果供后续整理。

无结果时：放宽关键词、去掉期刊限定词或生僻缩写，再试；延长 `--years` 作为后备。记录实际使用的查询。

### 第 3 步：期刊分区分类，交用户选择

1. 对每篇检索结果，用 web 搜索确认最终发表期刊，并按期刊水准分区（如 Phys. Rev. A/B 视为二区、Phys. Rev. Lett. 视为一区；此处分区指期刊水准而非学科）。
2. 查不到发表期刊的归为「未发表 / arXiv 预印本」。
3. 按分区分组整理成清单（表格：arXiv ID / 标题 / 期刊 / 分区）发给用户，请用户选择 3/5/10 篇用于下载源码（用户未指定时默认 5 篇）。
4. 这是人工确认门禁：用户未确认前不得进入第 4 步，不要自行决定下载。

### 第 4 步：下载 TeX 源码

对用户选定的论文运行：

```bash
python scripts/download_arxiv_sources.py 2401.00001 2401.00002 --out work/tex_sources
```

脚本从 `https://arxiv.org/e-print/<id>` 下载并自动解包（tar.gz / 单文件 gz / 纯 tex），每篇一个子目录。若某篇没有 TeX 源码（如仅 PDF），记录并在第 5 步改为从 PDF 提取文本。

### 第 5 步：相似段落匹配与整合（核心）

逐篇执行：

1. 打开该论文 `.tex` 源码，搜索与初稿共有的理论/方法关键词（例如已发表论文同样使用 Floquet 理论且引用了同一原始文献，初稿也使用了 Floquet 理论）。
2. 定位互补段落（引言背景、公式推导细节、方法说明），评估与初稿内容的相似度。
3. 改写并裁剪进初稿对应位置，同时补全引用（`\cite`）与参考文献条目；不允许大段照搬原文。
4. 重复本步骤直至所有选定论文整合完成。完成后向用户汇报：论文完成约 95%，剩余查重、精修、补缺需人工配合（可继续协助逐段修改）。

## 本科生场景（变体）

- 作者为本科生时：第 2 步改为中国知网（https://www.cnki.net）按关键词检索；分类仍按期刊分区；获取全文后以 PDF 文本提取内容（无 TeX 源码），其余步骤相同。

## 规范与边界

- 学术诚信：所有移植内容必须改写并正确引用，最终必须过查重；优先引用原始文献。
- 中间文件（检索结果 JSON、下载源码）统一放在工作目录，不写入论文目录。
- 第 3 步是人工确认门禁：未获得用户选择前不得进入下载与整合。
